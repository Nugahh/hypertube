Default profile pictures. The picker in the profile page and the picture given to members who have not uploaded one
both come from index.json: to add your own images, copy them here and add a line to index.json:

  { "file": "my-picture.png", "name": "My picture" }

File names: lowercase letters, digits and hyphens only (e.g. my-picture.png); svg, png, webp or jpg.

The class icons (feca.png ... forgelance.png) are the Dofus class symbols from https://api.dofusdb.fr/img/breeds/,
cropped to a square. They are (c) Ankama: used here as fan content in a school project, not for any commercial use.
Check Ankama's terms before publishing this project, and only add other images you have the right to use.
